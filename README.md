# Bumble Profile Analysis | Python

## Project Overview
This project focuses on analyzing Bumble profile data using Python to identify demographic patterns, lifestyle preferences, income distribution, and geographic trends.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Cleaning
- Identified and handled missing values.
- Removed columns with more than 50% missing values.
- Removed duplicate records.
- Converted last_online into datetime format.

## Feature Engineering
- Created age groups.
- Categorized income levels.
- Calculated days since last online.
- Created profile completeness scores.
- Converted height from inches to centimeters.
- Applied StandardScaler to numerical features.

## Exploratory Data Analysis

### 1. Demographic Analysis
- Gender distribution.
- Age distribution.
- Relationship status analysis.
- Relationship status by gender.

### 2. Lifestyle Analysis
- Diet preferences.
- Drinking habits.
- Diet and drinking relationship.

### 3. Geographic Analysis
- Top 5 cities by users.
- Top 5 states by users.
- Average age by city.
- Average income by state.

### 4. Income Analysis
- Income distribution.
- Income by age group.
- Income by gender.
- Income by gender and relationship status.

### 5. Correlation Analysis
- Relationship between age, height, and income.
- Correlation heatmap.

## Project Files
- Bumble_Profile_Analysis.ipynb – Complete Python analysis.
- bumble.csv – Anonymized dataset used for analysis.

## Key Learnings
Practiced data cleaning, feature engineering, exploratory data analysis, statistical analysis, and data visualization using Python.

## Conclusion
This project demonstrates practical Python skills in analyzing profile data and identifying demographic, lifestyle, income, and geographic patterns.
